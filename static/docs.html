API Reference

All endpoints support both X-API-Key header and ?api_key= query param.

🔐 Authentication

Add your API key to every request via header or query param:

# Option A: Header (recommended)
GET /api/info?url=...
X-API-Key: mapi_your_key_here

# Option B: Query param
GET /api/info?url=...&api_key=mapi_your_key_here
401 — Invalid/missing key
429 — Rate limit exceeded
